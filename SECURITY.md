# Security and proof integrity

Report vulnerabilities or proof-integrity issues privately through the repository's GitHub Security Advisory interface. Include the revision, toolchain pins, reproducible command and affected theorem or numerical boundary. Do not include credentials or customer data. You can also report privately to enterprise@pandora-world.com. Do not post exploit details in a public issue.

Release candidates receive fixes through reviewed changes and a new candidate version. No production support SLA is implied. Numerical outputs and runtime consistency reports are not formal certificates. Promotion requires the release checks and an approved source revision; any unknown or unapproved transitive axiom blocks promotion.
